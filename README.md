# multi-agent-mvp
本项目解决企业运营中多任务效率低、协作复杂、通知缺失的问题。传统人工或单脚本方式效率低且易出错。MVP提供通用自动化骨架，支持多Agent并行执行任务，异步调度并记录任务状态，实现跨任务协作。  用户通过React前端创建任务，调用FastAPI后端接口，将任务分发给多Agent调度器。每个Agent独立完成子任务（如数据抓取、处理、报表生成），任务完成后汇总结果，并通过Webhook占位（如飞书）发送通知。SQLite数据库记录任务状态和结果，为报表和分析提供基础。  项目核心特点：多Agent并行执行、异步调度、前后端分离、Webhook通知占位、数据库记录、可扩展接入多平台。整体逻辑流为：前端→后端→多Agent协作→Webhook通知→数据库，形成可控、高效、可扩展的自动化运营流程。
